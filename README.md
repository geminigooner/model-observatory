# The Model Observatory - Pilot# The Model Observatory

An interactive research environment for exploring foundation-model behavior through semantic geometry.

**Track:** Indie Developer | **Theme:** Push the Frontier (Science)

## Research Question
How does controlled contextual variation (neutral vs. affectionate system context)
influence the observable semantic representations of Muse Spark outputs?

## Status
Hackathon build in progress (Oct 26 - Nov 4). See DEVLOG.md

## Method
Black-box behavioral analysis. External text embeddings of model outputs —
not Muse internal activations. Measurements are computed in original
high-dimensional space before 2D projection for visualization.

## Built with
Muse Spark (experimental subject + collaborator)
